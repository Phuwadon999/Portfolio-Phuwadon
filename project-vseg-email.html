Web Application

VSEG University Email Web

เว็บแอปพลิเคชันจำลองระบบอีเมลสำหรับมหาวิทยาลัย รองรับผู้ใช้ทั้งนักศึกษาและอาจารย์ โดดเด่นด้วยระบบ Authentication, การจัดการ Inbox/Event และหน้า Admin Panel โดยนำระบบขึ้นใช้งานจริงบนคลาวด์

บทบาทที่รับผิดชอบ Full-Stack Development, Cloud Deployment, UI/UX Design
เครื่องมือที่ใช้ Node.js, HTML/CSS/JS, Azure App Service, Azure SQL, GitHub, Figma
ปีที่จัดทำ 2024

ฟีเจอร์สำคัญ

  • ออกแบบ UI/UX และ User Flow ของระบบทั้งหมดผ่าน Figma
  • พัฒนา Frontend (HTML/CSS/JS) และ Backend (Node.js) โดยประยุกต์ใช้ AI ช่วยเขียนโค้ด
  • ออกแบบและเชื่อมต่อฐานข้อมูลผ่าน Azure SQL Database เพื่อจัดการข้อมูลผู้ใช้และอีเมล
  • ทดสอบระบบและนำโปรเจกต์ Deploy ขึ้นสู่ระบบคลาวด์ของ Azure App Service
